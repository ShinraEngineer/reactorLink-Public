# ReactorLink

Fluxer and Discord in one window, each signed in as you - with themes, smooth animations and a dashboard of its own. It's free, and it updates itself.

## Download

Grab the latest from the [**Releases**](https://github.com/ShinraEngineer/reactorLink-Public/releases/latest) page:

- **Windows** - `ReactorLink-Setup.exe`. It installs for just you (no admin) and puts a shortcut on your desktop. The first time, Windows may say "Windows protected your PC" (I don't pay for a signing certificate) - click **More info**, then **Run anyway**.
- **Linux** - `ReactorLink.AppImage`. Make it executable (right-click > Properties > "Allow executing as program", or `chmod +x`), then double-click it. Nothing to install. If double-clicking does nothing on Ubuntu, run `sudo apt install libfuse2` once and try again.
- **Mac, or to run it from a folder** - download `ReactorLink.zip`, unzip it somewhere it won't get moved, and read `READ ME FIRST.txt` inside.

Once it's installed it keeps itself up to date: when there's a new version a download icon shows up at the top right - click it and it restarts updated.
